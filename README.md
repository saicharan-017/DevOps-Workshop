## 📌 Overview

A practical DevOps learning and implementation repository focused on understanding how applications move from development to deployment.

The repository is intended to document hands-on work with version control, Linux, containers, cloud deployment, server management and performance testing.

## 🎯 What This Project Covers

    ↓
